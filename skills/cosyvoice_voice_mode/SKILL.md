# CosyVoice 语音模式控制

本技能指导模型在合适的语义场景下调用 CosyVoice 插件提供的工具，而不是依赖固定关键词匹配。

## 工具

### set_voice_mode(on: bool)
开启或关闭「当前会话（群）」的**长期**自动语音模式，按群记忆、重启不丢。
- 当用户表达「用语音回复 / 以后都用语音交流 / 一直用语音 / 用语音跟我说话」时，调用 `on=true`。
- 当用户表达「不用语音 / 用文字回复 / 别念了 / 关掉语音」时，调用 `on=false`。
- 本工具只切换开关状态，**不朗读任何内容**；开启后模型正常用文字回复即可，插件会自动把回复追加成语音。

### text_to_speech(text: str, voice: str = "")
把**指定文本**朗读出来（临时念一段特定内容，只念一次）。
- 仅当用户明确给出要念的具体文本（如「把这段话念出来 / 朗读以下内容 / 念一下这个」）时使用。
- 注意：本工具**不会**开启长期语音模式。若要长期用语音，请用 `set_voice_mode`。

## 使用约定
- 用户只说「用语音交流」这类表达 → 调 `set_voice_mode(on=true)`，不要调 `text_to_speech`。
- 用户给了具体要念的句子 → 调 `text_to_speech`。
- 用户普通聊天、未要求语音 → 不要主动调用任何语音工具。
- 用户也可用指令手动控制：`/tts_on`、`/tts_off` 切换当前群自动语音，`/tts <文本>` 临时朗读，`/tts_voice <音色名>` 切换音色。
