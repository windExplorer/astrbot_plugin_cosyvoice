# CosyVoice 语音模式控制

本技能指导模型在合适的语义场景下调用 CosyVoice 插件提供的工具，而不是依赖固定关键词匹配。会话范围包括**群聊和私聊**，开关按「当前会话」独立记忆、重启不丢。

## 工具

### set_voice_mode(on: bool)
开启或关闭「当前会话（群聊或私聊均可）」的**长期**自动语音模式，按会话记忆、重启不丢。
- 当用户表达「从此以后我都会发语音消息 / 以后都用语音回复 / 一直用语音跟我说话」时，调用 `on=true`。
- 当用户表达「以后不用发语音了 / 用文字回复就行 / 别念了 / 关掉语音」时，调用 `on=false`。
- 本工具只切换开关状态，**不朗读任何内容**；开启后模型正常用文字回复即可，插件会自动把回复追加成语音。

### text_to_speech(text: str, voice: str = "")
把**指定文本**朗读出来（临时念一段特定内容，只念一次）。
- 仅当用户明确给出要念的具体文本（如「把这段话念出来 / 朗读以下内容 / 念一下这个」）时使用。
- 注意：本工具**不会**开启长期语音模式。若要长期用语音，请用 `set_voice_mode`。
- 若当前会话**已开启语音模式**（用户此前说过「用语音回复」/已 `/tts_on`/已 `set_voice_mode(on=true)`，或全局 `auto_tts` 开启），**不要**调用本工具：插件会自动把最终回复合成语音，再调本工具会多一条孤立语音、还把回复拆成「调工具前 / 调工具后」多条消息。直接把要说的写进文字回复即可。

### list_voices()
列出当前所有可用音色名称。当用户问「你有哪些声音 / 能换成什么音色 / 都有什么嗓音」时调用，方便用户挑选后配合 `set_voice` 切换。

### set_voice(name: str)
切换「当前会话（群聊或私聊均可）」长期使用的音色，按会话独立记忆、重启不丢。当用户说「以后用 XX 的声音 / 换成 XX 音色 / 用小明的嗓音」时调用。
- 本工具只切换音色、**不朗读内容**；切换后该聊天之后的语音都用这个新音色。
- 调用前若不确定有哪些音色，先调 `list_voices` 拿到可用名称，`name` 必须是其中之一。

## 使用约定
- 用户说「从此以后我都会发语音消息」这类表达 → 调 `set_voice_mode(on=true)`，不要调 `text_to_speech`。
- 当前会话**已经开启语音模式**（`/tts_on` 已开 / 已 `set_voice_mode(on=true)` / 全局 `auto_tts` 开启）时：
  - **不要**调用 `text_to_speech` 工具，插件会自动朗读最终回复；再调它既多一条孤立语音，又会把回复拆成多条消息。
  - 不要先写「我画了图 / 念了语音 / 给你读了」这类复述再行动，**直接一次性把要说的写成最终文字回复**，插件会整段念出来，回复始终只有「一条文字 + 一条语音」。
- 用户给了具体要念的句子 → 调 `text_to_speech`。
- 用户想换音色（如「换成小明的声音 / 以后用小红念」）→ 调 `set_voice(name=音色名)`；若不记得有哪些音色，先调 `list_voices`。
- 用户问有哪些声音可选 → 调 `list_voices`。
- 用户明确要求「用文字回复 / 发文字 / 这段别念 / 不用语音念」→ 本条只发文字，**不要**强行合成语音；插件会自动抑制本条语音（不改变 tts_on 开关，后续仍按原模式）。注意这与「关闭语音模式」不同：关闭要用 `set_voice_mode(on=false)`，而「要文字」只是本条特例。
- 用户普通聊天、未要求语音 → 不要主动调用任何语音工具。
- 用户也可用指令手动控制：`/tts_on`、`/tts_off` 切换当前会话自动语音（群聊和私聊都适用），`/tts <文本>` 临时朗读，`/tts_voice <音色名>` 切换当前聊天的音色（按会话持久保存），`/tts_voice` 不带参数可查看可用音色列表。
